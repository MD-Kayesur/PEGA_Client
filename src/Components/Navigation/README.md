# রিঅ্যাক্ট রেসপন্সিভ ন্যাভিগেশন কম্পোনেন্ট

এই কম্পোনেন্টটি রিঅ্যাক্ট অ্যাপ্লিকেশনের জন্য একটি সম্পূর্ণ রেসপন্সিভ ন্যাভিগেশন তৈরি করে। এতে রয়েছে ডেস্কটপ ও মোবাইল ভার্সনে আলাদা মেনু, মাল্টি লেভেল সাবমেনু, সার্চ ফাংশন এবং ক্লিন স্ট্রাকচার।

---

## বৈশিষ্ট্য

- রেসপন্সিভ ডিজাইন (Tailwind CSS ব্যবহার করে)
- মাল্টি লেভেল ড্রপডাউন মেনু সাপোর্ট
- মোবাইল ফ্রেন্ডলি হ্যামবার্গার মেনু
- সার্চ বাটন ও ইনপুট টগল
- ক্লিন ফোল্ডার স্ট্রাকচার

---

### প্রয়োজনীয় প্যাকেজ
React Router DOM (রাউটিংয়ের জন্য)

React Icons (আইকনের জন্য)

Tailwind CSS (স্টাইলিংয়ের জন্য)

ইন্সটলেশন:
 
bash ``` npm install react-router-dom react-icons ```




মেনু ডেটা ফাইল (menue.json)
মেনু এর ডাটা public/menue.json ফাইলে রাখা হয়েছে, যেখানে মাল্টি লেভেল মেনু সাপোর্ট করা হয়েছে:

 
[
  {
    "menu": "Home",
    "src": "home"
  },
  {
    "menu": "Shop",
    "sub": [
      { "menu": "Men", "src": "shop/men" },
      { "menu": "Women", "src": "shop/women" }
    ]
  }
]




ব্যবহৃত স্টেট
 
 
const [mobileMenuOpen, setMobileMenuOpen] = useState(false);
const [openSubMenu, setOpenSubMenu] = useState(null);
const [serch, setserch] = useState(false);
mobileMenuOpen - মোবাইল মেনুর ওপেন/ক্লোজ নিয়ন্ত্রণ করে।

openSubMenu - সাবমেনু ওপেন-হবার ইনডেক্স নির্ধারণ করে।

serch - সার্চ বক্স টগল করে।




মোবাইল ভার্সন
হ্যামবার্গার মেনু দিয়ে মেনু ওপেন-বন্ধ করা যায়।

সাবমেনু একটিভেট করার জন্য আলাদা টগল রয়েছে।

সার্চ বক্স আলাদা টগল করা যায়।

ডেস্কটপ ভার্সন
গ্রুপ হোভার এর মাধ্যমে ড্রপডাউন মেনু প্রদর্শন।

ফিক্সড পজিশনিং এবং ট্রানজিশন ব্যবহার করে সাবমেনু।

সার্চ আইকন ও "Try Pega" বাটন যুক্ত।

ভবিষ্যৎ উন্নয়ন (ফিউচার প্রুফ)
সার্চ স্টেট গ্লোবালি ব্যবস্থাপনার জন্য Context API ব্যবহার করা।

রিকার্সিভ মেনু তৈরি করা (যাতে সাবমেনুর সংখ্যা বাড়লেও সহজেই মেনেজ হয়)।

এনিমেশন অ্যাড করা (যেমনঃ Framer Motion দিয়ে)।

টাইপসক্রিপ্ট ব্যবহার করে আরও সেফ কোড লেখা।

সার্চের সাথে ডাটা ফিল্টার ইন্টিগ্রেট করা।

কিভাবে ব্যবহার করবেন

function App() {
  return (
    <div>
      <Navigation />
      {/* অন্যান্য কম্পোনেন্ট */}
    </div>
  );
}

export default App;
